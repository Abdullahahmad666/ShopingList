# Shopping List — Android App

An Android shopping-list app with user accounts: sign up, log in, and add, view and manage the items on your list. Data syncs through **Firebase**.

## Features
- Animated splash screen
- Sign-up and login with Firebase Authentication
- Add new items to your list
- Shopping list with a custom adapter

## Tech
Java · Kotlin (theme) · XML · Firebase · Android Studio

## Run
1. Open in Android Studio and sync Gradle
2. Add your own `google-services.json` from Firebase to `app/`
3. Run on an emulator or device
